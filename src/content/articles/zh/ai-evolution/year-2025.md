## DeepSeek-R1：开源推理革命（2025.01.20）

DeepSeek 在 1 月 20 日发布 R1，震撼 AI 圈：
- **推理能力媲美 OpenAI o1**
- **完全开源**（MIT 协议）- 权重、代码、训练数据全公开
- **训练成本不到$6M** - 证明「低成本+高性能」可行

### 影响

- 打破「推理能力=巨额投资」的迷思
- 加速 AI 民主化进程
- 引发「开源 vs 闭源」路线的激烈讨论

## Agent Skills 诞生：架构问题而非智能问题（2025.10.16）

**2025 年 10 月 16 日**，Anthropic 发布 [Agent Skills](https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills)，这不是偶然。

### 核心洞察

> 「随着 agents 变得更强大，我们需要更可组合、可扩展、可移植的方式为它们装备领域专业知识。**这不主要是模型智能问题，而是架构问题** - agents 缺乏结构化的方式来存储、检索和重用过程知识。」

### 问题场景

```typescript
// MCP时代的困境（2024年）
const agent = new Agent({
  tools: [github, database, slack] // ✓ 有能力
});

用户: "帮我做code review"

AI:
// ✗ 有工具，但不知道如何使用
1. 应该先看什么？PR描述还是代码？
2. 审查顺序是什么？
3. 公司的审查标准是什么？
4. 如何写review comments？
5. 何时approve？

→ 结果：AI有刀但不会切菜
```

### Skills 的解决方案

```markdown
# code-review.skill.md

## Metadata
name: code-review
description: Perform professional code reviews
triggers: ["review", "PR", "pull request"]

## Instructions
1. 先读 PR 描述，理解改动目的
2. 检查测试覆盖率
3. 审查代码逻辑
4. 检查安全漏洞
5. 给出建设性反馈

## Company Standards
- 每个函数必须有单元测试
- 不允许 console.log
- API 需要错误处理
...

→ 结果：AI 有刀也会切菜了 ✓
```

## Claude Sonnet 4.5：百万 token 时代（2025.09.29）

Anthropic 在 9 月 29 日发布 Sonnet 4.5（Claude Code 内核）：
- **1M token 上下文** - 相当于 3000 页文档
- **代码能力再突破** - SWE-bench Verified 达 77.2%
- **实时协作** - Claude Code CLI 重新定义 AI 编程

### 上下文演进到 1M

```
对比：
2022.11: 4K tokens
2023.07: 100K tokens (25x 增长)
2025.10: 1M tokens (250x 增长)

实际应用：
- 分析整个代码库（10 万行+代码）
- 处理长篇报告、法律文档
- 多轮对话保持完整上下文
```

## Claude Opus 4.5：软件工程新标杆（2025.11.24）

Anthropic 在 11 月 24 日发布 Claude Opus 4.5：
- **SWE-bench Verified 达 80.9%** - 超越 Sonnet 4.5 的 77.2%
- **全球最佳编程模型** - 「世界上最好的编程、Agent 和计算机使用模型」
- **成本降低** - $5/M 输入 + $25/M 输出（Opus 4.1 的 1/3 价格）
- **架构级理解** - 不仅写代码，还能理解整个系统设计

### 意义

- AI 从「编码助手」升级为「软件工程师」
- 标志着 AI 可以独立完成中等复杂度的完整功能
- 为 Claude Cowork 等后续产品铺平道路

## 2025.12.18：开放标准时刻

### 历史性转折

Anthropic 宣布将 Agent Skills 规范变成**开放标准**：

### 关键决策

1. **公开规范** - 任何人都能实现
2. **MIT 许可** - 商业友好
3. **跨平台兼容** - 不绑定 Claude

### 立即效果

```
2025.12.18 - Anthropic 发布标准
2025.12.20 - OpenAI 悄悄采用（Codex CLI）
2025.12.22 - ChatGPT 集成 Skills 格式
2025.12.25 - Google 宣布 Gemini 支持
2026.01.05 - Microsoft 集成到 Copilot

→ 不到 1 个月，行业统一
```

## Prompt 工程的衰落（2024-2025）

### 数据不会说谎

```
LinkedIn 职位数据（2024-2025）:
"Prompt Engineer"头衔：↓ 40%
"AI Workflow Design"技能：↑ 25%

Indeed 职位搜索：
2023.04 - 峰值
2024.06 - 下降 50%
2025.01 - 下降 70%

招聘趋势：
"Prompt Engineer"独立岗位：基本消失
技能融入其他角色：成为标配
```

### 为什么衰落？

**原因 1：AI 模型变聪明了**

```
2023 年模型：
用户: "帮我写个排序函数"
AI: "什么排序？什么语言？"

2025 年模型：
用户: "帮我写个排序函数"
AI: "我注意到你的项目是 TypeScript，
这是一个支持泛型的快速排序实现..."

→ 模型能理解上下文，推断意图
→ 不再需要精心设计的 Prompt
```

**原因 2-4**：见 [3.2 Prompt 工程的兴衰](/blog/ai-evolution/prompt-engineering/)
