## GitHub Copilot Goes Commercial (2022.06.21)

Copilot, built by GitHub with OpenAI, went commercial on June 21 at $10/month. It was the first AI coding assistant sold at scale. For the first time, programmers felt what “AI pair programming” could do.

### Key innovations

- **Code completion** — context-aware suggestions
- **Multi-language support** — dozens of languages
- **GitHub integration** — wired into the development workflow

### Impact

- Code completion accuracy reached 40%
- Development speed improved by 30-50%
- Paved the way for the AI dev tools that followed
- Created a new product category: the AI coding assistant

### Why it mattered

> Copilot was AI's first step from “conversation toy” to “productivity tool”. It proved a model could help a programmer write code, not just answer questions.

---

## ChatGPT Lands (2022.11.30)

OpenAI shipped ChatGPT on November 30. One million users in 5 days, 100 million in two months — a growth record for an internet product. Not the first chatbot. The first one that made ordinary people feel “the AI actually gets me”.

### Key innovations

- **RLHF** (reinforcement learning from human feedback) — taught the model to talk like a person
- **Instruction following** — reads what the user actually wants
- **Safety alignment** — refuses harmful requests

### Impact

- Non-technical people could use AI for the first time
- Set off a global wave of AI applications
- Opened the “prompt engineering” era

### Versus Copilot

- **Copilot** — coding only, built for developers
- **ChatGPT** — general conversation, anyone can use it
- Together they set off the 2023 explosion

## The Context Starting Point: Trouble in the 4K Era

### Context in 2022

| Model | Context length | Real limit |
|------|-----------|---------|
| GPT-3.5 | 4K tokens | ~3000 characters of text |
| GPT-4 (2023.03, early) | 8K tokens | ~6000 characters of text |

### Pain points at the time

```
User: "Analyze this 20-page report for me"
AI: ✗ "The document is too long. Please send it in chunks."

Developer: "Analyze this 1,000-line code file"
AI: ✗ "I can only see the first 500 lines"

Long conversation:
User: "Remember the plan we discussed 10 minutes ago?"
AI: ✗ "Sorry, I've forgotten it"
```

**Those limits forced the long-context breakthrough**, which became the key battleground in 2023.

## Prompt Engineering Takes Root (2022)

### Early experiments

```markdown
Prompt practice in 2022:

Plain conversation:
User: "Write a function"
AI: [outputs code]

First pass at optimization:
User: "You are a Python expert. Write a sorting function."
AI: [outputs better code]

→ People start to realize "how you ask" matters
```

### Early signs

- An “Awesome ChatGPT Prompts” repo shows up on GitHub
- The first batch of prompt-technique articles appears
- No systematic methodology yet

### Why it matters

These early experiments set the foundation for the golden age of prompt engineering in 2023.
