## DeepSeek-R1：开源推理革命（2025.01.20）

DeepSeek在1月20日发布R1，震撼AI圈：
- **推理能力媲美OpenAI o1**
- **完全开源**（MIT协议）- 权重、代码、训练数据全公开
- **训练成本不到$6M** - 证明"低成本+高性能"可行

### 影响

- 打破"推理能力=巨额投资"的迷思
- 加速AI民主化进程
- 引发"开源vs闭源"路线的激烈讨论

## Agent Skills诞生：架构问题而非智能问题（2025.10.16）

**⏱️ 2025年10月16日**，Anthropic[发布Agent Skills](https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills)，这不是偶然。

### 核心洞察

> "随着agents变得更强大，我们需要更可组合、可扩展、可移植的方式为它们装备领域专业知识。**这不主要是模型智能问题，而是架构问题** - agents缺乏结构化的方式来存储、检索和重用过程知识。"

### 问题场景

```typescript
// MCP时代的困境（2024年）
const agent = new Agent({
  tools: [github, database, slack] // ✅ 有能力
});

用户: "帮我做code review"

AI:
// ❌ 有工具，但不知道如何使用
1. 应该先看什么？PR描述还是代码？
2. 审查顺序是什么？
3. 公司的审查标准是什么？
4. 如何写review comments？
5. 何时approve？

→ 结果：AI有刀但不会切菜
```

### Skills的解决方案

```markdown
# code-review.skill.md

## Metadata
name: code-review
description: Perform professional code reviews
triggers: ["review", "PR", "pull request"]

## Instructions
1. 先读PR描述，理解改动目的
2. 检查测试覆盖率
3. 审查代码逻辑
4. 检查安全漏洞
5. 给出建设性反馈

## Company Standards
- 每个函数必须有单元测试
- 不允许console.log
- API需要错误处理
...

→ 结果：AI有刀也会切菜了 ✅
```

## Claude Sonnet 4.5：百万token时代（2025.09.29）

Anthropic在9月29日发布Sonnet 4.5（Claude Code内核）：
- **1M token上下文** - 相当于3000页文档
- **代码能力再突破** - SWE-bench Verified达77.2%
- **实时协作** - Claude Code CLI重新定义AI编程

### 上下文演进到1M

```
对比：
2022.11: 4K tokens
2023.07: 100K tokens (25x增长)
2025.10: 1M tokens (250x增长)

实际应用：
- 分析整个代码库（10万行+代码）
- 处理长篇报告、法律文档
- 多轮对话保持完整上下文
```

## Claude Opus 4.5：软件工程新标杆（2025.11.24）

Anthropic在11月24日发布Claude Opus 4.5：
- **SWE-bench Verified达80.9%** - 超越Sonnet 4.5的77.2%
- **全球最佳编程模型** - "世界上最好的编程、Agent和计算机使用模型"
- **成本降低** - $5/M输入 + $25/M输出（Opus 4.1的1/3价格）
- **架构级理解** - 不仅写代码，还能理解整个系统设计

### 意义

- AI从"编码助手"升级为"软件工程师"
- 标志着AI可以独立完成中等复杂度的完整功能
- 为Claude Cowork等后续产品铺平道路

## Prompt工程的衰落（2024-2025）

### 数据不会说谎

```
LinkedIn职位数据（2024-2025）:
"Prompt Engineer"头衔：↓ 40%
"AI Workflow Design"技能：↑ 25%

Indeed职位搜索：
2023.04 - 峰值
2024.06 - 下降50%
2025.01 - 下降70%

招聘趋势：
"Prompt Engineer"独立岗位：基本消失
技能融入其他角色：成为标配
```

### 为什么衰落？

**原因1：AI模型变聪明了**

```
2023年模型：
用户: "帮我写个排序函数"
AI: "什么排序？什么语言？"

2025年模型：
用户: "帮我写个排序函数"
AI: "我注意到你的项目是TypeScript，
这是一个支持泛型的快速排序实现..."

→ 模型能理解上下文，推断意图
→ 不再需要精心设计的Prompt
```

**原因2-4**：见[3.2 Prompt工程的兴衰](/blog/ai-evolution/prompt-engineering/)
