## The Claude 3 Family: Beating GPT-4 Across the Board (2024.03.04)

Anthropic shipped Claude 3 in three sizes:
- **Opus** — the flagship, first model to beat GPT-4 on multiple benchmarks
- **Sonnet** — the value pick, 2x GPT-4's speed
- **Haiku** — the fastest, built for scale

### Key breakthroughs

- **Vision** — reads charts, screenshots, handwritten notes
- **200K context** — stretches the long-document lead further
- **Near-perfect instruction following** — developer satisfaction spikes

### The context war escalates

```
Claude 3: 200K tokens
→ about a 500-page document
→ can analyze a large codebase (100,000 lines)
→ long conversations almost never "lose the thread"

Impact:
- GPT-4's 32K starts to look thin
- OpenAI is forced to accelerate context expansion
- Long context becomes table stakes, not a differentiator
```

## The Prompt Caching Breakthrough (2024.08.14)

### Anthropic's solution

```
How it works:
- cache the static parts: system prompt, tool definitions
- later requests send only what changed

Cost:
- cache hit: $0.30 / 1M tokens (10x cheaper)
- latency: ~90% of processing time saved

Limits:
- cache lives for 5 minutes
- static content only
```

### What it looked like in practice

```
Scenario: Claude Code development
- system prompt: 50K tokens
- tool definitions: 30K tokens
- MCP servers: 20K tokens
Total: 100K static tokens

First request: $3
Cache hit: $0.30 ✓ - 90% cheaper
```

### Why it mattered

- Cuts the cost of long context hard
- Makes calling AI constantly economically viable
- Paves the road for the Agent applications that followed

**But prompt engineering's other pain points stayed** — the ones that would force a more fundamental answer in 2025 (Agent Skills).

## OpenAI o1: A New Era of Reasoning (2024.09.12)

OpenAI shipped the o1 series (codename Strawberry) and put **Chain-of-Thought reasoning** front and center:
- It “thinks” first on hard problems, then answers
- Large gains in math, coding and scientific reasoning
- But slow and expensive, a bad fit for everyday chat

### Reasoning, side by side

```
GPT-4: answers immediately
o1: thinks for 10-30 seconds → then gives a deeper analysis

Where it fits:
✓ hard math problems
✓ algorithm design
✓ scientific reasoning
✗ everyday chat (too slow)
✗ simple tasks (waste)
```

## The MCP Protocol Arrives (2024.11.25)

Anthropic released the **Model Context Protocol**, pitched as the “USB-C port” for AI tools.

### The core pitch

- **One interface** — a single standard connects every AI tool
- **Cross-platform** — different models share the same tools
- **Isolation** — tool calls run sandboxed
- **Ecosystem** — the community ships new tools fast

### The hype cycle begins

```
2024.11 - release, GitHub frenzy
2024.12 - 100K downloads, "revolutionary"
```

### Early enthusiasm

- Developers were excited about the promise of “one standard”
- The community built MCP servers fast
- Heavy press coverage

### But the problems were already sprouting (they show up in 2025)

- Security risks got no attention
- Complexity from over-engineering
- Token efficiency problems
- Enterprise requirements unmet

## DeepSeek-V3: Open Weights Strike Back (2024.12.26)

DeepSeek, a Chinese AI startup, released V3:
- **671B MoE architecture** (mixture of experts)
- **Performance on par with GPT-4**, trained for $5.5M
- **Fully open weights**, breaking the closed-source giants' grip

### Why it mattered

- Proof that “low cost + high performance” works
- The open source community saw a path to catching the closed labs
- Set up the R1 reasoning shock of 2025
