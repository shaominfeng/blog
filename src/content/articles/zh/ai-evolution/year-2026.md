## Claude Cowork：AI 协作的新纪元（2026.01.12）

Anthropic 发布 [Claude Cowork](https://claude.com/blog/cowork-research-preview)，将 AI 从「对话工具」升级为「数字同事」。

### 核心能力

#### 1. 直接文件访问

```bash
# 给Claude访问项目文件夹
~/Projects/my-app
  ├── docs/ # Claude可读取文档
  ├── data/ # Claude可处理数据
  └── reports/ # Claude可生成报告
```

#### 2. 子代理协调

- **任务分解** - 将复杂任务拆分成子任务
- **并行执行** - 多个子代理同时工作
- **进度汇报** - 实时告知工作状态

#### 3. 专业输出

- **Excel** - 生成带公式的电子表格
- **PowerPoint** - 创建格式化的演示文稿
- **Word 文档** - 生成专业报告
- **图表可视化** - 数据分析与可视化

### 实际应用场景

```
场景 1：财务报表自动化
"分析 Q4 销售数据，生成带图表的 Excel 报表"
→ Claude 读取 CSV → 数据分析 → 生成 Excel + 图表

场景 2：会议纪要整理
"将这个录音转文字，整理成会议纪要 PPT"
→ 转录 → 提取要点 → 生成 PPT

场景 3：文档批量处理
"将 reports/文件夹下的 50 个 PDF 合并成一份综合报告"
→ 读取 PDF → 提取内容 → 生成 Word 文档
```

### 为什么 Cowork 重要

1. **降低门槛** - 非程序员也能用 AI 自动化工作
2. **真正的 Agent** - 不只回答问题，而是完成任务
3. **办公场景** - 直击知识工作者痛点
4. **生态扩展** - 结合 Skills，无限可能

## Clawdbot：本地 AI 助手的病毒式爆发（2026.01.24）

### 从个人项目到现象级

2025 年 11 月，PSPDFKit 创始人 Peter Steinberger 把 [Clawdbot](https://github.com/openclaw/openclaw) 放到 GitHub 上。它最初的定位很朴素：一个跑在自己机器上的个人 AI 助手，通过 WhatsApp、Telegram、Slack 这些已有的聊天工具接收指令，能读文件、执行命令、调用工具。发布时大约 5,000 颗星，属于圈内叫好的量级。

转折发生在 2026 年 1 月 24 日。几个演示视频在 X 和 Reddit 上扩散——AI 在 WhatsApp 里收到一句话，自己查航班、完成值机；另一个视频里，它同时管理 Telegram 与 Discord 的会话，还记住了几轮之前提过的偏好。当天项目登上 Hacker News 首页，星标数开始垂直上升。

### 爆火数据

72 小时之内，GitHub 星标从约 5,000 涨到 60,000 以上，一周后突破 18 万。到 2026 年 10 月，仓库已接近 39 万颗星，成为 GitHub 上星标最多的软件项目之一。

```
时间线：
2025.11.24 - 项目发布，约 5K stars
2026.01.24 - 登上 Hacker News 首页，演示视频扩散
2026.01.26 - 72 小时内 5K → 60K，单日新增约 2.5 万
2026.01.27 - Anthropic 提出商标异议，被迫改名
2026.01.30 - 定名 OpenClaw
2026.10 - 约 39 万 stars
```

外溢效应同样剧烈：Mac mini 一度断货，因为一个 7×24 小时在线的助手需要一台常开的机器。Google 的 Logan Kilpatrick 公开晒出自己的订单，MacStories 的 Federico Viticci 写了一周使用记录，Robert Scoble 整理了一份传播极广的报告。这个项目由此从开发者圈层进入到大众视野。

### 核心特性

```
个人 AI 超级助手
- 本地运行（数据留在自己机器上）
- 跨平台消息集成（WhatsApp、Telegram、Slack、Discord、iMessage）
- 完全开源（MIT 许可）
- 任何设备可跑（Mac、Linux、Windows、树莓派）
- 多模型支持（Claude、GPT、Gemini、本地模型）
- 持久记忆（Markdown 文件存在本地）
- 主动任务（Heartbeat 定时触发）
```

### 技术架构

- **Gateway 进程** - 单进程常驻，负责消息路由、会话状态与工具调度
- **渠道适配器** - WhatsApp、Telegram、Slack、Discord、iMessage、Teams
- **多模型后端** - Claude、GPT、Gemini，也可接本地 Llama
- **本地优先存储** - 记忆与配置以 Markdown / JSON 形式落在配置目录

### 为什么爆火？

#### 1. 数据的控制权回到使用者手里

与 Claude Cowork 的云端模式对照：

```
Cowork：会话与文件上下文经由 Anthropic 服务器
Clawdbot：Gateway、记忆、API Key 都在自己机器上
```

需要说明的是，「本地」解决的是数据归属，不是安全。这一点很快被现实补了一课，见本章最后一节。

#### 2. 复用已有的聊天界面

```
WhatsApp：帮我总结今天的会议
Slack：分析这份数据
Discord：写个脚本

无需切换到另一个 App，学习成本接近于零
```

#### 3. 开源带来的可改造性

```
- 添加新的消息平台
- 集成自己的工具链
- 定制回复风格与审批策略
- 连接公司内部系统
```

#### 4. 成本结构可选

```
方案 A：调用 Claude / GPT API，按用量付费
方案 B：本地模型（Llama、Mistral），一次性硬件成本
```

#### 5. 它解决的是「执行」，不是「回答」

社区里流传最广的一句评价是「带双手的 Claude」（Claude with hands）。这句话点出了它与聊天产品的根本差异：ChatGPT 告诉你怎么做，它直接做完给你看。

### 三个名字：一次改名事故

爆红的速度，很快引来了另一件事。

「Clawd」与 Anthropic 的「Claude」发音过于接近。2026 年 1 月 27 日，项目正处在指数增长期，Anthropic 的商标团队提出异议。商标保护要求权利人主动维权，否则有失权风险，从法律角度无可指摘；但在开发者社区看来，这成了「大公司对小项目施压」的典型案例。

Steinberger 选择配合，把项目改名为 Moltbot（molt，龙虾蜕壳）。改名操作在深夜进行：他先释放旧的组织名、再去注册新名字，中间大约有 10 秒空窗。

就这 10 秒，社交账号被抢注，一个假的 CLAWD 代币在 Solana 上线，几小时内市值冲到 1,600 万美元，随后崩盘九成。Moltbot 这个名字也没被社区接受，几天后项目最终定名 OpenClaw。

### 安全账：爆红 72 小时里的另一面

项目的技术选择本身没有大问题，问题出在默认配置和实际部署方式上。三件事在同一个窗口内发生：

- **900 多个实例暴露在公网**。安全研究者 Jamieson O'Reilly 用 Shodan 扫描 Gateway 的默认 HTML 标题，发现大量控制面板没有认证。根因是「本地回环免认证」这一设计假设：Gateway 信任来自 127.0.0.1 的连接，而当用户把反向代理部署在同一台机器上时，所有外部请求都以 127.0.0.1 的身份进来，认证被整体绕过。
- **凭证明文存放**。API Key、Bot Token、会话历史以明文 JSON / Markdown 落在配置目录。RedLine、Lumma、Vidar 三个信息窃取木马在 48 小时内加上了针对性采集模块。
- **一键 RCE**。CVE-2026-25253（CVSS 8.8）允许通过诱导用户点击链接，在宿主机上执行任意代码。

这一课对做 Agent 平台的人格外直接：**给 Agent 权限，等于给攻击面权限**。本地部署降低的是数据外流的风险，不降低被入侵的风险。

## Agent 时代全面来临

### 2026 年初的 AI 生态

```
编程开发：
- Claude Code（CLI + Skills）
- GitHub Copilot Workspace
- Cursor / Windsurf

办公协作：
- Claude Cowork
- Microsoft Copilot
- Google Workspace AI

个人助手：
- OpenClaw（本地）
- ChatGPT（云端）
- Gemini（集成）

垂直领域：
- 医疗 AI 助手
- 法律 AI 助手
- 教育 AI 助手

共同特点：
✓ 自主规划任务
✓ 调用多种工具
✓ 处理复杂流程
✓ 生成专业输出
```

### Agent 化的核心要素（2026）

1. **Skills** - 领域知识和最佳实践
2. **Tools** - 原生能力（bash、python、read、write）
3. **MCP** - 外部集成（按需）
4. **长上下文** - 保持任务状态
5. **推理能力** - 复杂决策

## 本章总结

2026 年是协作时代的开启之年：

- **Claude Cowork**：AI 数字同事，办公自动化
- **Clawdbot / OpenClaw**：本地 AI 助手病毒式传播（72 小时从 5K 到 60K stars）
- **Agent 时代全面来临**：编程、办公、个人助手全面 Agent 化

**关键启示**：云端和本地 AI 各有市场，协作成为核心价值。

---

## 云端 vs 本地：两条平行路线

| 特性 | 云端 AI（Cowork） | 本地 AI（OpenClaw） |
|------|----------------|-------------------|
| **隐私** | 数据上传云端 | 完全本地 ✓ |
| **性能** | 最新最强模型 ✓ | 取决于硬件 |
| **成本** | 按使用付费 | 一次性硬件投入 ✓ |
| **网络依赖** | 需要联网 | 离线可用 ✓ |
| **定制性** | 有限 | 完全自由 ✓ |
| **易用性** | 开箱即用 ✓ | 需要配置 |

**结论**：不是谁取代谁，而是各取所长。
