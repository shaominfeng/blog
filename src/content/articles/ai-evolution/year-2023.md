## GPT-4：多模态能力的飞跃（⏱️ 2023.03.14）

GPT-4在3月14日发布，首次实现文本+图像的多模态理解，能力全面超越GPT-3.5。

### 关键突破

- **多模态** - 理解图片、图表、手写内容
- **上下文扩展** - 8K标准版，32K扩展版
- **推理能力** - 数学、编程、科学推理大幅提升

### 但问题也浮现

- 高昂的API价格（$0.03/1K输入，$0.06/1K输出）
- 速度限制和排队
- 32K版本价格更贵，不适合高频使用

**这为Claude的差异化竞争创造了机会**。

## Claude的崛起：Anthropic的差异化路线（⏱️ 2023.03-07）

### Claude 1.0（2023.03）

Anthropic由OpenAI前研究副总裁Dario Amodei创立，主打"Constitutional AI"（宪法AI）理念，强调安全性和可解释性。

### Claude 2.0（⏱️ 2023.07.11）

**100K token上下文**震撼业界：

```
对比：
GPT-4: 8K/32K tokens
Claude 2: 100K tokens ← 相当于一本300页的书！

实际影响：
- 可以分析整本书
- 可以理解中型代码库
- 长对话不再频繁"失忆"
```

### 为什么Claude脱颖而出

1. **更安全**：减少有害输出，适合企业应用
2. **更长的记忆**：处理长文档、代码库分析
3. **更好的代码能力**：成为开发者新宠

## 上下文里程碑：从4K到100K

### ⏱️ 2023年的上下文战争

| 时间 | 模型 | 上下文 | 增长倍数 | 意义 |
|------|------|-------|---------|------|
| 2022.11 | GPT-3.5 | 4K | 基准 | ChatGPT时代 |
| 2023.03 | GPT-4 | 8K→32K | 2-8x | 多模态突破 |
| 2023.07 | Claude 2 | 100K | 25x | **长文本元年** |

### 100K上下文解决了什么

```
✅ 长文档理解：
之前: "文档太长，请分段"
现在: "一次性分析整本书"

✅ 代码库分析：
之前: "只能看单个文件"
现在: "理解整个模块（50+文件）"

✅ 多轮对话：
之前: "10轮后开始遗忘"
现在: "几十轮保持完整记忆"
```

### 但新问题出现

- 成本线性增长（100K上下文 = 25倍成本）
- 延迟增加（处理时间变长）
- 如何有效利用长上下文？

这些问题将在2024-2025年逐步解决（Prompt Caching、Auto-Compact等）。

## Prompt工程黄金时代（⏱️ 2023）

[职位搜索数据](https://fortune.com/2025/05/07/prompt-engineering-200k-six-figure-role-now-obsolete-thanks-to-ai/)：

```

→ "未来最热门技能"

培训班爆发：

- 7天成为Prompt专家

```

### 流行的Prompt技巧

```markdown
1. Chain-of-Thought (CoT)
"让我们一步步思考..."

2. Few-shot Learning
"这里有3个例子：
例1: ...
例2: ...
例3: ...
现在处理：..."

3. Role Playing
"你是一个资深的XXX专家，拥有20年经验..."

4. Tree-of-Thought
"探索多个可能的解决路径..."

5. ReAct (Reasoning + Acting)
"思考 → 行动 → 观察 → 思考..."
```

### Prompt库爆发

- Awesome ChatGPT Prompts（GitHub 10万+ stars）
- PromptBase（Prompt交易市场）
- FlowGPT（Prompt社区）
- 企业Prompt管理平台

### 但暗流涌动

- Prompt结果不稳定
- 学习曲线陡峭
- 难以维护和版本控制
- 黑盒调试令人沮丧

这些痛点将在2024-2025年引发Prompt工程的衰落，并催生新的解决方案（Skills、DSPy等）。
