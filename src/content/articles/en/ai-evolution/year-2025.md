## DeepSeek-R1: The Open-Source Reasoning Revolution (2025.01.20)

DeepSeek shipped R1 on January 20 and jolted the whole field:
- **Reasoning on par with OpenAI o1**
- **Fully open source** (MIT) — weights, code, training data, all of it public
- **Training cost under $6M** — proof that “low cost + high performance” is real

### Impact

- Breaks the myth that reasoning ability equals enormous spend
- Speeds up AI democratization
- Sets off a fierce open vs. closed debate

## Agent Skills: An Architecture Problem, Not an Intelligence Problem (2025.10.16)

**October 16, 2025**. Anthropic publishes [Agent Skills](https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills). This was not an accident.

### The core insight

> “As agents get more capable, we need more composable, extensible, and portable ways to equip them with domain expertise. **This is not primarily a model intelligence problem — it's an architecture problem**: agents lack a structured way to store, retrieve, and reuse procedural knowledge.”

### The problem

```typescript
// The MCP-era predicament (2024)
const agent = new Agent({
  tools: [github, database, slack] // ✓ capable
});

user: "do a code review for me"

AI:
// ✗ has the tools, no idea how to use them
1. What do I read first? The PR description or the code?
2. What order do I review in?
3. What are the company's review standards?
4. How do I write review comments?
5. When do I approve?

→ Result: the AI has the knife, but cannot chop.
```

### The Skills fix

```markdown
# code-review.skill.md

## Metadata
name: code-review
description: Perform professional code reviews
triggers: ["review", "PR", "pull request"]

## Instructions
1. Read the PR description first, understand what the change is for
2. Check test coverage
3. Review the code logic
4. Check for security holes
5. Give constructive feedback

## Company Standards
- Every function needs a unit test
- No console.log
- APIs need error handling
...

→ Result: the AI has the knife, and can chop now. ✓
```

## Claude Sonnet 4.5: The Million-Token Era (2025.09.29)

Anthropic shipped Sonnet 4.5 on September 29 (the core of Claude Code):
- **1M token context** — roughly 3000 pages of documents
- **Coding jumps again** — 77.2% on SWE-bench Verified
- **Real-time collaboration** — Claude Code CLI redefines AI programming

### Context grows to 1M

```
Comparison:
2022.11: 4K tokens
2023.07: 100K tokens (25x growth)
2025.10: 1M tokens (250x growth)

In practice:
- Analyze an entire codebase (100,000+ lines)
- Work through long reports and legal documents
- Hold full context across multi-turn conversations
```

## Claude Opus 4.5: The New Bar for Software Engineering (2025.11.24)

Anthropic shipped Claude Opus 4.5 on November 24:
- **80.9% on SWE-bench Verified** — past Sonnet 4.5's 77.2%
- **The best coding model anywhere** — “the best model in the world for coding, agents, and computer use”
- **Cheaper** — $5/M input + $25/M output (a third of Opus 4.1's price)
- **Architectural understanding** — not just writing code, but reading the whole system design

### Why it matters

- AI goes from “coding assistant” to “software engineer”
- Marks the point where AI can ship a complete feature of moderate complexity on its own
- Paves the way for products like Claude Cowork

## 2025.12.18: The Open Standard Moment

### The turning point

Anthropic announces it will turn the Agent Skills spec into an **open standard**:

### Key decisions

1. **Public spec** — anyone can implement it
2. **MIT license** — commercially friendly
3. **Cross-platform** — not tied to Claude

### Immediate effect

```
2025.12.18 - Anthropic publishes the standard
2025.12.20 - OpenAI quietly adopts it (Codex CLI)
2025.12.22 - ChatGPT integrates the Skills format
2025.12.25 - Google announces Gemini support
2026.01.05 - Microsoft ships it in Copilot

→ Under one month, and the industry is aligned
```

## The Decline of Prompt Engineering (2024-2025)

### The data doesn't lie

```
LinkedIn job data (2024-2025):
"Prompt Engineer" titles: ↓ 40%
"AI Workflow Design" skills: ↑ 25%

Indeed job search:
2023.04 - peak
2024.06 - down 50%
2025.01 - down 70%

Hiring trend:
"Prompt Engineer" as a standalone role: basically gone
The skill folds into other roles: table stakes
```

### Why did it decline?

**Reason 1: the models got smarter**

```
2023 model:
user: "write me a sort function"
AI: "What kind of sort? Which language?"

2025 model:
user: "write me a sort function"
AI: "I see your project is TypeScript.
Here's a quicksort implementation with generics..."

→ The model reads context and infers intent
→ Carefully crafted prompts are no longer needed
```

**Reasons 2-4**: see [3.2 The Rise and Fall of Prompt Engineering](/blog/en/ai-evolution/prompt-engineering/)

## MCP Cools Off (2025-2026)

### The hype cycle

```
2024.11 - Released, GitHub goes wild
2024.12 - 100K downloads, "revolutionary"
2025.01 - Community MCP servers explode
2025.03 - OpenAI announces MCP support
2025.04 - 8M downloads
2025.04 - Security holes surface (2000 servers with no auth)
2025.12 - Anthropic donates it to the AAIF foundation
2026.01 - Interest drops, reality sets in
```

### Problems surface

Details: [3.3 The MCP Protocol: From Hype to Reality](/blog/en/ai-evolution/mcp/)

### MCP isn't dead. It found its niche.

- Tools that genuinely need cross-platform reuse
- Enterprise tool integration (once security is hardened)
- Complementary to Skills, not competing with them
