## GPT-4：多模态能力的飞跃（2023.03.14）

GPT-4 在 3 月 14 日发布，首次实现文本+图像的多模态理解，能力全面超越 GPT-3.5。

### 关键突破

- **多模态** - 理解图片、图表、手写内容
- **上下文扩展** - 8K 标准版，32K 扩展版
- **推理能力** - 数学、编程、科学推理大幅提升

### 但问题也浮现

- 高昂的 API 价格（$0.03/1K 输入，$0.06/1K 输出）
- 速度限制和排队
- 32K 版本价格更贵，不适合高频使用

**这为 Claude 的差异化竞争创造了机会**。

## Claude 的崛起：Anthropic 的差异化路线（2023.03-07）

### Claude 1.0（2023.03）

Anthropic 由 OpenAI 前研究副总裁 Dario Amodei 创立，主打「Constitutional AI」（宪法 AI）理念，强调安全性和可解释性。

### Claude 2.0（2023.07.11）

**100K token 上下文**震撼业界：

```
对比：
GPT-4: 8K/32K tokens
Claude 2: 100K tokens ← 相当于一本 300 页的书！

实际影响：
- 可以分析整本书
- 可以理解中型代码库
- 长对话不再频繁"失忆"
```

### 为什么 Claude 脱颖而出

1. **更安全**：减少有害输出，适合企业应用
2. **更长的记忆**：处理长文档、代码库分析
3. **更好的代码能力**：成为开发者新宠

## 上下文里程碑：从 4K 到 100K

### 2023 年的上下文战争

| 时间 | 模型 | 上下文 | 增长倍数 | 意义 |
|------|------|-------|---------|------|
| 2022.11 | GPT-3.5 | 4K | 基准 | ChatGPT 时代 |
| 2023.03 | GPT-4 | 8K→32K | 2-8x | 多模态突破 |
| 2023.07 | Claude 2 | 100K | 25x | **长文本元年** |

### 100K 上下文解决了什么

```
✓ 长文档理解：
之前: "文档太长，请分段"
现在: "一次性分析整本书"

✓ 代码库分析：
之前: "只能看单个文件"
现在: "理解整个模块（50+ 文件）"

✓ 多轮对话：
之前: "10 轮后开始遗忘"
现在: "几十轮保持完整记忆"
```

### 但新问题出现

- 成本线性增长（100K 上下文 = 25 倍成本）
- 延迟增加（处理时间变长）
- 如何有效利用长上下文？

这些问题将在 2024-2025 年逐步解决（Prompt Caching、Auto-Compact 等）。

## Prompt 工程黄金时代（2023）

### 2023 年 4 月 - 巅峰时刻

[职位搜索数据](https://fortune.com/2025/05/07/prompt-engineering-200k-six-figure-role-now-obsolete-thanks-to-ai/)：

```
Indeed 搜索量：
2023.04 - 峰值
→ "年薪$20 万的新兴职业"
→ "未来最热门技能"
→ 各种 Prompt 工程师招聘

媒体报道：
- "学会 Prompt 月薪 3 万"
- "不会编程也能做 AI 工程师"
- "Prompt 工程师是下一个风口"

培训班爆发：
- Prompt Engineering 课程$999
- 7 天成为 Prompt 专家
- ChatGPT 提示词大全
```

### 流行的 Prompt 技巧

```markdown
1. Chain-of-Thought (CoT)
"让我们一步步思考..."

2. Few-shot Learning
"这里有 3 个例子：
例 1: ...
例 2: ...
例 3: ...
现在处理：..."

3. Role Playing
"你是一个资深的 XXX 专家，拥有 20 年经验..."

4. Tree-of-Thought
"探索多个可能的解决路径..."

5. ReAct (Reasoning + Acting)
"思考 → 行动 → 观察 → 思考..."
```

### Prompt 库爆发

- Awesome ChatGPT Prompts（GitHub 10 万+ stars）
- PromptBase（Prompt 交易市场）
- FlowGPT（Prompt 社区）
- 企业 Prompt 管理平台

### 但暗流涌动

- Prompt 结果不稳定
- 学习曲线陡峭
- 难以维护和版本控制
- 黑盒调试令人沮丧

这些痛点将在 2024-2025 年引发 Prompt 工程的衰落，并催生新的解决方案（Skills、DSPy 等）。
