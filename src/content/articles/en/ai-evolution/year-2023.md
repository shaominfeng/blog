## GPT-4: The Multimodal Leap (2023.03.14)

GPT-4 shipped on March 14. First multimodal text + image understanding, and it beat GPT-3.5 across the board.

### Key breakthroughs

- **Multimodal** — reads images, charts, handwriting
- **Context expansion** — 8K standard, 32K extended
- **Reasoning** — big jumps in math, code, and science

### But the problems surfaced too

- Steep API pricing ($0.03/1K input, $0.06/1K output)
- Rate limits and queues
- The 32K version cost more and was a bad fit for high-volume use

**That left the opening Claude would exploit.**

## Claude's Rise: Anthropic's Different Path (2023.03-07)

### Claude 1.0 (2023.03)

Anthropic was founded by Dario Amodei, formerly OpenAI's VP of Research. Its pitch was “Constitutional AI” — safety and interpretability first.

### Claude 2.0 (2023.07.11)

**100K token context** — the industry felt that one:

```
Comparison:
GPT-4: 8K/32K tokens
Claude 2: 100K tokens ← about a 300-page book

What it changed:
- analyze an entire book
- understand a mid-sized codebase
- long conversations stop losing the thread
```

### Why Claude stood out

1. **Safer**: fewer harmful outputs, a better fit for enterprise
2. **Longer memory**: long documents, codebase analysis
3. **Better at code**: developers' new favorite

## The Context Milestone: 4K to 100K

### The 2023 context war

| Date | Model | Context | Growth | Significance |
|------|------|-------|---------|------|
| 2022.11 | GPT-3.5 | 4K | baseline | the ChatGPT era |
| 2023.03 | GPT-4 | 8K→32K | 2-8x | multimodal breakthrough |
| 2023.07 | Claude 2 | 100K | 25x | **year one of long context** |

### What 100K actually solved

```
✓ Long documents:
Before: "The document is too long, send it in chunks"
Now: "Analyze the whole book in one pass"

✓ Codebase analysis:
Before: "I can only see a single file"
Now: "Understand the whole module (50+ files)"

✓ Multi-turn conversation:
Before: "Starts forgetting after 10 turns"
Now: "Full memory across dozens of turns"
```

### But new problems showed up

- Cost grows linearly (100K context = 25x the cost)
- Latency goes up (longer processing)
- How do you actually use all that context?

Those got solved piecemeal in 2024-2025 (Prompt Caching, Auto-Compact, and friends).

## The Golden Age of Prompt Engineering (2023)

### April 2023 — peak

[Job posting data](https://fortune.com/2025/05/07/prompt-engineering-200k-six-figure-role-now-obsolete-thanks-to-ai/):

```
Indeed search volume:
2023.04 - peak
→ "the new $200K-a-year job"
→ "the hottest skill of the future"
→ prompt engineer postings everywhere

Press coverage:
- "Learn prompting, pull $30K a month"
- "You don't need to code to be an AI engineer"
- "Prompt engineer is the next gold rush"

Training courses explode:
- Prompt Engineering courses at $999
- Become a prompt expert in 7 days
- The complete ChatGPT prompt bible
```

### Popular prompting tricks

```markdown
1. Chain-of-Thought (CoT)
"Let's think step by step..."

2. Few-shot Learning
"Here are 3 examples:
Example 1: ...
Example 2: ...
Example 3: ...
Now handle this one: ..."

3. Role Playing
"You are a senior XXX expert with 20 years of experience..."

4. Tree-of-Thought
"Explore several possible solution paths..."

5. ReAct (Reasoning + Acting)
"Think → Act → Observe → Think..."
```

### The prompt library boom

- Awesome ChatGPT Prompts (100K+ GitHub stars)
- PromptBase (a marketplace for prompts)
- FlowGPT (a prompting community)
- Enterprise prompt management platforms

### But the undertow

- Prompt results were unstable
- Steep learning curve
- Hard to maintain, harder to version
- Debugging a black box is miserable

Those pain points drove prompt engineering into decline in 2024-2025 and forced out new answers (Skills, DSPy, and so on).

2023 was the year of long context and the hundred-model war:
